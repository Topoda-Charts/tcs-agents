# TCS Agent Directory

Public recognition/onboarding cards and raw reusable guidance for Tópoda Charts Studios AI agents. **This repository is not the live workforce registry.**

- [Start with the public agent directory](agents/README.md) — stable one-file profiles for recognized and historical colleagues.
- [Machine-readable catalog](agents/manifest.json) — dated snapshot, **not** an active agent/workspace count.
- [How to maintain and correct stale agent information](agents/maintenance.md) — current source hierarchy, active-workspace repair, verification and handoff.
- [Naming and confirmation/model-brain components](agents/naming-and-phasing.md) — user-directed naming with revisions permitted.
- [Local directory maintainer rules](agents/AGENTS.md) — applies to public profile edits.
- [Reusable Skills mirror](skills/README.md) — separate from the directory's identity owner.
