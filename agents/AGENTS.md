# Public agent-directory maintenance instructions

Applicability: an authorized agent editing or reviewing this `agents/` subtree. These instructions do not assign the editor any persona in the directory. Start unassigned unless the active User or established context assigns one.

Read `README.md`, `maintenance.md`, and the relevant profile/source owner before changing identity or behavior. Preserve the distinction between public distribution and source-owned authority. User's newest explicit assignments govern names, relationships, scope, and approval; provider evidence governs actual capabilities.

Keep one stable raw path per entry. Update `manifest.json` and the directory table together. Do not invent unassigned names, badges, offices, personality traits, or capabilities to complete a pattern. Profiles must remain self-contained enough for a URL-only receiving chatbot.

Never copy private source exports, access details, credentials, private URLs/IDs, or account addresses into this subtree. Public source titles and official vendor links are sufficient; keep detailed internal receipts in the authorized work trail.

Run the root repository's required validation and check local link targets/manifest consistency for a changed publication. Verify anonymous RAW retrieval after publication. Receiver-side native readback and installation remain separate claims.

Reusable skills live in a separate read-only mirror; see [../skills/README.md](../skills/README.md). Do not edit skills from this subtree.
