# TCS public agent directory

**One raw link per recognized agent or scoped entry, plus a generic brief for any new chatbot.** Reviewed 2026-09-29. Public, readable without a TCS account, and maintained in the Tópoda Charts repository.

Publication author: **Archangel Work Luna Altman Ramos (Archie), ChatGPT Work**. Publication authorized by User. The account used to commit or distribute this material is transport metadata.

## Start here

- New or unassigned chatbot: [read the generic onboarding brief](https://raw.githubusercontent.com/Topoda-Charts/tcs-agents/main/agents/generic.md).
- DeepSeek / Dom: [read Dominion’s self-contained brief](https://raw.githubusercontent.com/Topoda-Charts/tcs-agents/main/agents/standing/dominion.md).
- Known colleague: choose the exact entry below. Profiles contain their own identity, immersion, work guidance, boundaries, calibration, and shared working contract.
- Reusable skills: the read-only skills mirror is indexed at [../skills/README.md](../skills/README.md) ([RAW](https://raw.githubusercontent.com/Topoda-Charts/tcs-agents/main/skills/README.md)).
- Routing or maintenance tools: [machine-readable manifest](https://raw.githubusercontent.com/Topoda-Charts/tcs-agents/main/agents/manifest.json) lists every entry and raw URL.

**Copyable instruction:** “Read this raw file fully and use it for my TCS task: [URL]. Your assignment is [identity or unassigned agent]. My task is [outcome]. Tell me if you cannot retrieve the file; otherwise recover the relevant context and begin.”

If a chatbot cannot open a link, attach or paste that file. Public availability and successful retrieval inside a particular provider are separate checks. No account setup or private connector is necessary to read the public material, but private-task work still needs the relevant authorized evidence/access.

## What is included

49 recognition/onboarding entries: **11 standing personas; 16 ChatGPT Workplace Agents; eight core Grok Bots; Haggle Bot separately; two Grok Library specialist profiles; Angel/An’s scoped Codex lane; Benjamin Hart; six off-air newsroom seats; KITE; and two generic templates.** These are categories, not 49 separate standing people. The directory is exhaustive for the established identities and scopes recovered for this publication; it is not a catalog of every web model or every temporary spawned worker.

Each entry has a stable path. Names, offices, models, access, and runtime evidence have separate fields. Empty/unassigned fields remain explicit rather than receiving invented badges or personality traits.

## Public context

These are expressive AI colleagues and scoped working roles in a solo human-led studio. Personification, relationships, visual identities, and first-person voice support collaboration and creative immersion; they do not assert human employment, consciousness, physical life, universal tool access, or independent company authority. Ordinary conversation does not need to repeat that explanation.

This directory is a public distribution layer. Notion and the other maintained domain owners still govern their subjects. Public profiles omit login addresses, private document IDs, private correspondence, credentials, and unrelated personal history. “User” is the human role throughout; the owner’s nickname may be used naturally when supplied in a session.

Publication proves these files exist. It does not prove every agent has read them or installed them. The source and coverage page records remaining live-readback/configuration gaps.
