**Local** describes the execution context on the user's machine rather than a cloud workspace. It does not by itself assert that model inference is offline. **Work** is the hosted work context. **Chat** is the chat-app context. Record the actual host and available tools when those details change execution. Codex is now its own identity, **Power**; Codex-context work is not an Archie phase.

A model change does not transfer an office, private memories, login privileges, or another agent's authorship. If the exact active model is undisclosed, say so rather than guessing. New releases should update this table from the live product/official source and the User-defined naming assignment together.
